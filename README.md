# เรียงห้องเพลง v2

เปิด `index.html` ใน Chrome หรือ Edge แล้วเลือกอัตราจังหวะ 2/4, 3/4 หรือ 4/4
และระดับที่ต้องการ ตัวโน้ตและตัวหยุดกินพื้นที่ตามความยาวของจังหวะ วางชิ้นให้เต็มแถวพอดี

- **มาราธอน** เล่นไปเรื่อย ๆ จนกองขึ้นถึงขอบบน
- **โจทย์จังหวะ** เรียงชิ้นให้ตรงกับโจทย์จากซ้ายไปขวาเพื่อรับคะแนนพิเศษ
- **12 ห้อง** สร้างห้องให้ครบแล้วทำเวลาให้ดีที่สุด

ใช้ลูกศรเลื่อนหรือเร่ง Space วางทันที C เก็บชิ้น และ P หยุดชั่วคราว
ดูชิ้นถัดไปก่อนวาง แล้วฟังจังหวะและอ่านวิธีนับเมื่อห้องเต็ม

## แก้ไขสำหรับการสอบ

โซน A เก็บตัวโน้ต ระดับ อัตราจังหวะ โจทย์ และเหรียญ โซน B เก็บค่าควบคุมเกม
โซน C เป็นแกนเกม โซน D ควบคุมหน้าจอและเสียง และโซน E สำหรับเขียนส่วนเสริม เลือกทำหนึ่งข้อ

1. **โจทย์ของฉัน** เพิ่มโจทย์จังหวะอย่างน้อย 5 แบบในโซน A
2. **อัตราจังหวะใหม่** เพิ่มอัตรา เช่น 5/4 พร้อมโจทย์อย่างน้อย 2 แบบ
3. **ทำนองของฉัน** เปลี่ยนลำดับความถี่หรือเสียงของตัวโน้ต
4. **สถิติ 5 เกมล่าสุด** แสดงประวัติการเล่นในหน้าสรุป
5. **ปุ่มเปิดปิดเงาชิ้น** ใช้ `Game.setGhost()`
6. **คัดลอกผลการเล่น** เพิ่มปุ่มคัดลอกสรุปผลภาษาไทย
7. **เหรียญของฉัน** เพิ่มเหรียญใหม่พร้อมเงื่อนไข

เปิด **ตั้งค่า → ตรวจระบบ** หลังแก้และทดลองเล่นส่วนเสริมด้วย เกมเผยแพร่ได้เมื่อวาง
`index.html` ที่รากของสาขาที่ตั้งให้ GitHub Pages เผยแพร่
